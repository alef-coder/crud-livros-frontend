# Frontend – Minha Biblioteca (PWA)

HTML, CSS e JavaScript puros que consomem a API de livros.

## Executar localmente

1. Inicie o backend na porta 3000.
2. Nesta pasta, rode: `npx serve .`
3. Abra o endereço mostrado no terminal (não abra o index.html direto).

## Endereço da API

Definido no topo do `app.js`, na constante `API_BASE`.
Depois do deploy, troque `http://localhost:3000` pela URL do Render.
